# appgr

Sauvegarde de l’artefact claude.ai « appgr » (préparation GR20).

- `index.html` : page autonome, ouvrable directement dans un navigateur.
- Sauvegarde automatique (vérification toutes les heures) : un commit n’est créé que si l’artefact a changé.

Les données (séances importées, objectif) restent dans le navigateur (localStorage) et ne sont pas dans ce dépôt.
